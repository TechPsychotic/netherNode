# Security policy

## Supported versions

Only the latest release gets security fixes. Everyone playing together should update, since netherNode versions don't always connect across minor versions.

## Reporting a vulnerability

Please **don't open a public issue**. Report it privately through GitHub: go to the [Security tab](https://github.com/TechPsychotic/netherNode/security/advisories/new) and choose *Report a vulnerability*.

Include what's affected, how to reproduce it and what an attacker could do. You'll get a reply within a week, and credit in the release notes if you want it.

Areas that matter most:

- *Invite friends*, *Join friend* and the friends list (the tunnel, codes and who gets let in)
- Servers hosted through netherNode (approval, whitelist, extra ports)
- Downloads and checksums (game files, Java, loaders, mods, authlib-injector)
- The local skin service
