    A command line for everything

    The nethernode binary does everything the app does.

    $ nethernode instance create modded 1.21.1 --loader fabric
$ nethernode mods add modded sodium
$ nethernode server start smp --share
$ nethernode share join maple orbit tunnel frog

    The End · Your stuff

    Nothing phoned home

    No accounts, analytics or telemetry. netherNode only talks to Mojang (game files and Java), Modrinth, the loader and Paper sites when you install those, and iroh's relay for playing with friends.

    Your journey starts here

    Download the latest release for your computer.

    Windows10 and 11, x64 (runs on ARM).zip macOS11+, Intel and Apple Silicon.dmg Linuxx64, any distro.tar.gz
    The builds aren't code-signed yet. Here's how to open them.
    • Windows: if SmartScreen appears, click More info, then Run anyway.
    • macOS: right-click the app, choose Open, then Open again. If macOS says it's damaged, run xattr -dr com.apple.quarantine /Applications/netherNode.app.
    • Linux: extract, then run ./install.sh to add netherNode to your app menu. Minecraft 1.12.2 and older also need xrandr.

    Or build it yourself with Rust:

    $ git clone https://github.com/TechPsychotic/netherNode
$ cd netherNode && cargo build --release
